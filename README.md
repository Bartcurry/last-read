# 最后一条已读

单文件 H5 悬疑解谜游戏。玩家解锁一部陌生人的手机，翻聊天、相册、便签和水电账单，用**数据反常**去推翻口供。

- 案件：
  - `case_001 · 完美合租人` —— 合租的屋子里只住着一个人
  - `case_002 · 值夜的人` —— 泵报过九次警，记录簿只有一次
- 形态：一个 `index.html`（内联 CSS + JS，无构建、无依赖、无后端）
- 加新案子：写一个与 `CASE_001` 同结构的对象，塞进 `CASES` 数组即可，不用改渲染逻辑
- 存档：浏览器 `localStorage`（带 `SCHEMA` 版本号，内容改动后老档自动作废）
- 在线试玩：<https://bartcurry.github.io/last-read/>

## 玩法

1. **锁屏**：4 位 PIN。线索在锁屏那张回忆卡片上。
2. **四个板块**：信鸽（会话）、相册（含最近删除）、记录（便签/订单/设备）、信息（短信）。
3. **搜索**：已注销的会话不在列表里，需要在信鸽顶部按名字搜出来。
4. **私密相册**：加密，需要额外 4 位 PIN。线索在信息里。
5. **结案**：三轮「矛盾举证」，每轮从证据池里出示 **2 份**证据推翻一句口供。
   只有翻过的板块，其证据才可出示；锁在私密相册里的证据需要先解锁，关于林静的证据需要先找到她。
6. **结尾**：草稿箱里那条没发出去的话，由你决定发还是删。

没有凶手，没有尸体。只有一个人被删掉了。

## 目录

```
.
├── index.html              游戏本体（唯一入口）
├── manifest.webmanifest    PWA：可「添加到主屏幕」全屏运行
├── assets/photos/          5 张正片照片 1080×1350（WebP）
├── assets/icons/           PWA 图标 192 / 512 / 180
├── store/                  TapTap 后台素材（图标/截图/宣传图/说明）
└── .nojekyll               跳过 GitHub Pages 的 Jekyll 处理
```

## 本地运行

直接双击 `index.html` 即可。若浏览器限制 `file://` 下的 `localStorage`，起一个静态服务：

```bash
python -m http.server 8000
```

## 部署

托管在 GitHub Pages，来源为 `main` 分支根目录（`/`），推送即自动发布。
`index.html` 里的 `og:image` / `og:url` 用的是绝对地址，换域名时需要同步修改。
