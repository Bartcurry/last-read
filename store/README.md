## 二、逐个文件 → 后台字段

| 文件 | 后台位置 | 规格 | 验收要点 |
|---|---|---|---|
| `icon_512.png` | 应用图标 / ICON | 512×512 正方形 PNG | 主体（气泡+红点）最远点距中心约 217px，**在圆形裁切安全区内**，被裁成圆角或圆形都不会切到图形 |
| `icon_1024.png` | 同上（若后台收高清） | 1024×1024 PNG | 同一张图的 2× 版本，不是另画一张 |
| `promo_1920x1080.png` | 宣传图 / 封面图 | 1920×1080，16:9 | 左文案右双机位；缩到 320px 宽仍能读出「最后一条已读」 |
| `screenshot_01…05` | 游戏截图（横版） | 每张 1920×1080 | 5 张，满足「≥3 张、≥1280×720」；按 01→05 顺序上传 |
| `portrait/01…10` | 截图（竖版，可选） | 每张 1170×2532（390×844 @3x） | 后台若只收横图，这一组留作分享卡片 / 社区帖素材 |

**图标为什么长这样**：气泡＝聊天，红点＝未读，合起来就是标题「最后一条已读」。
没有文字、没有人物、没有 UI 截图——任何尺寸下都不会糊成一团。已在 48px 下验证过仍可辨认。

## 四、上传顺序建议

1. 先传 `icon_512.png`（后台通常卡这一步才能继续）
2. 再传 `screenshot_01 → 05`，按编号顺序，第一张是转化率最高的一张

## 五、还没做的

| 项 | 说明 |
|---|---|
| **宣传视频** | 后台通常要一段 15–30s 视频。分镜建议：0–3s 锁屏输入 0612 → 3–8s 相册四张照片快切（毛巾/胶带/黑线/插座）→ 8–13s 举证页选两份证据 → 13–15s 弹出「矛盾成立」→ 标题。**核心机制必须在前 5 秒出现**，这是审核和转化的共同要求 |
| **ICP 备案** | H5 走网页版上线必须有备案号，这是全流程里唯一不可压缩的等待项，越早提交越好 |
| **隐私政策链接** | 后台一般要求填一个可访问的 URL。游戏本身不收集任何数据（纯本地 localStorage），照实写即可 |

## 六、素材复现方式

截图来自 `最后一条已读_v0.6.html` 在 390×844 视口下的真实渲染（3× 缩放），
不是手工摆拍。改了游戏逻辑后要重出截图，重跑一遍渲染脚本即可，不要手工 PS。

排版脚本用 Pillow 在 2× 画布（3840×2160）上绘制后降采样到 1920×1080，
所以文字边缘是抗锯齿的，不会像直接 1× 输出那样发虚。
